# НД-16-00 — другий рік Python, 2026–2027

У репозиторії збережено навчальні напрацювання групи: попередні приклади агента-розробника та початкову структуру RPG-проєкту.

## Структура RPG — 18.10.2026

На занятті готували промпт і продумували базові класи для різних типів сутностей. У папці `rpg/` є заготовки класів персонажів і тварин (`entities`), екіпірування (`equipments`) та здобичі (`loot`). Класи містять лише початкові оголошення, наслідування й описи; ігрову логіку ще не реалізовано.

## Попередні приклади агента — стан на 27.09.2026

- `test_api.py` — приклад підключення до OpenAI API; у ньому залишено безпечний маркер ключа.
- `RPG_Master.py` — конфігураційний початок майбутньої RPG. Гру тут ще не реалізовано.
- `Code_Writer.py` — отримує задачу через `input`, формує контекст і запит до моделі. Є опис `list_files`, локальна функція перегляду Python-файлів і вибір обробника за назвою інструмента. Виклик обробника в циклі відповіді та повернення результату моделі ще не підключені.
- `player.py` — клас `Player` із початковим здоров'ям `hp = 100`.

## Локальний запуск

Потрібен Python 3.10 або новіший. У PowerShell у папці проєкту виконайте:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

У файлі, який запускаєте (`test_api.py` або `Code_Writer.py`), замініть `YOUR_OPENAI_API_KEY` на свій ключ OpenAI API лише в локальній копії. Не надсилайте ключ у GitHub, чат або інші публічні місця. Перед комітом поверніть маркер `YOUR_OPENAI_API_KEY` або працюйте з окремим локальним файлом, який ігнорується Git.

## Важливо

Навчальний код збережено на поточному етапі без виправлення оригіналу. Під час перегляду відповіді в `Code_Writer.py` лишилося написання `argumets` замість `arguments`. Синтаксична коректність Python сама по собі не підтверджує правильність роботи агента.

Запуск `test_api.py` чи `Code_Writer.py` робить справжній запит до OpenAI API і може списувати кошти з вашого акаунта. Під час підготовки цього публічного знімка API-запити не запускалися; перевірено синтаксис і вилучення ключа. `player.py` не звертається до API.
