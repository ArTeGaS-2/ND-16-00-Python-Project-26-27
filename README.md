# НД-16-00 — Python: перший проєкт 2026–2027

Це навчальний знімок початку роботи з Python та OpenAI API. У репозиторії є лише код, потрібний для цього етапу уроку.

## Що є на цьому етапі

- `test_api.py` — приклад підключення до OpenAI API; у ньому залишено безпечний маркер ключа.
- `RPG_Master.py` — конфігураційний початок майбутньої RPG. Гру тут ще не реалізовано.
- `Code_Writer.py` — порожня заготовка для наступного заняття.

## Локальний запуск

Потрібен Python 3.10 або новіший. У PowerShell у папці проєкту виконайте:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Потім у локальній копії `test_api.py` замініть `YOUR_OPENAI_API_KEY` на свій ключ OpenAI API. Не надсилайте ключ у GitHub, чат або інші публічні місця. Перед комітом поверніть маркер `YOUR_OPENAI_API_KEY` або працюйте з окремим локальним файлом, який ігнорується Git.

## Важливо

Запуск `test_api.py` робить справжній запит до OpenAI API і може списувати кошти з вашого акаунта. У цьому публічному знімку API-запити не запускалися.
