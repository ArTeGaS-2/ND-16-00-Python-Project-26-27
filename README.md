# НД-16-00 — другий рік Python, 2026–2027

Це навчальний знімок роботи над агентом-розробником для текстової RPG. У репозиторії збережено код, до якого дійшли на занятті 20.09.2026.

## Що є на цьому етапі

- `test_api.py` — приклад підключення до OpenAI API; у ньому залишено безпечний маркер ключа.
- `RPG_Master.py` — конфігураційний початок майбутньої RPG. Гру тут ще не реалізовано.
- `Code_Writer.py` — отримує задачу через `input`, формує контекст і запит до моделі. Додано допоміжну функцію опису інструментів, опис `list_files` і цикл перегляду елементів відповіді. Виконання Python-функцій для читання й редагування файлів агентом ще не підключене.
- `player.py` — клас `Player` із початковим здоров'ям `hp = 100`.

## Локальний запуск

Потрібен Python 3.10 або новіший. У PowerShell у папці проєкту виконайте:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

У файлі, який запускаєте (`test_api.py` або `Code_Writer.py`), замініть `YOUR_OPENAI_API_KEY` на свій ключ OpenAI API лише в локальній копії. Не надсилайте ключ у GitHub, чат або інші публічні місця. Перед комітом поверніть маркер `YOUR_OPENAI_API_KEY` або працюйте з окремим локальним файлом, який ігнорується Git.

## Важливо

Навчальний код збережено на поточному етапі без виправлення оригіналу. Перед API-запуском потрібно виправити назви службових полів у `Code_Writer.py`: `parametrs` → `parameters`, `propetries` → `properties`, `request` → `required`, `argumets` → `arguments`. Синтаксична коректність Python сама по собі не підтверджує правильність API-схеми.

Запуск `test_api.py` чи `Code_Writer.py` робить справжній запит до OpenAI API і може списувати кошти з вашого акаунта. Під час підготовки цього публічного знімка API-запити не запускалися; перевірено синтаксис і вилучення ключа. `player.py` не звертається до API.
