# Вправи з пошуку помилок

Добірка містить 42 короткі навчальні заготовки. У файлах навмисно залишено синтаксичні помилки, помилки виконання або розбіжності з очікуваним результатом. Опис на початку кожного файла задає мету вправи.

Спочатку передбачте результат, знайдіть причину розбіжності, змініть потрібний рядок і перевірте маленький приклад. Кожна вправа виконується окремо; це не готова програма.

У вправі 1 лічильник голосних збільшується всередині циклу, а print зараз показує проміжне значення після кожного символу. Перевірте, де має стояти print, щоб показати один підсумок.

Добірку додано до репозиторію після заняття 04.10.2026. Це не означає, що всі 42 вправи виконано на цьому занятті. У прикладі анкети використано знеособлені вигадані дані.
