# Замовлення піци — 01.11.2026

Початок окремої вправи з класом `Order`: словник доступних додатків, поле розміру піци та метод введення цього розміру. `main.py` поки порожній; завершеної програми замовлення ще немає.

Код збережено як на занятті. У підказці методу залишено `/n` замість символу нового рядка `\n`; `input` повертає текст. Вибір додатків, перевірка розміру та обчислення вартості ще не реалізовані.

Для прикладу достатньо стандартного Python. Викликів зовнішніх API тут немає.
